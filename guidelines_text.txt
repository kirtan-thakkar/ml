Project Instructions 
1. Project Title 
End-to-End Machine Learning Project: From Data Exploration to Model Evaluation 
2. Project Objective 
The objective of this project is to enable students to apply the complete Machine Learning workflow 
to a real-world dataset. Students will identify a suitable problem, select an appropriate dataset from 
a recognized public repository, analyse and preprocess the data, develop suitable Machine Learning 
models, evaluate and compare their performance, and communicate their findings. 
The project emphasizes learning by doing and requires students to understand the complete ML 
pipeline rather than applying an algorithm in isolation. 
3. Learning Outcomes 
• 
Formulate a clear real-world problem suitable for Machine Learning. 
• 
Select and understand a suitable dataset from Kaggle or the UCI Machine Learning Repository. 
• 
Perform data cleaning, exploratory data analysis, preprocessing, and feature engineering. 
• 
Select appropriate Machine Learning algorithms based on the problem and data. 
• 
Train, validate, tune, and evaluate Machine Learning models. 
• 
Compare models using appropriate performance metrics. 
• 
Interpret results, analyse errors, and justify modelling decisions. 
• 
Document and present the complete Machine Learning workflow professionally. 
4. Project Team and Constraints 
• 
The project must be completed in a team of 2–3 students. 
• 
A team cannot have more than 3 members (Inter-batch project teams are not permitted). 
• 
Each team must work on a clearly defined Machine Learning problem. 
• 
Each team must use a dataset obtained from either Kaggle or the UCI Machine Learning 
Repository. 
• 
The selected dataset must be sufficiently meaningful for applying an ML pipeline; very small toy 
datasets should not be selected. 
• 
Teams must finalize both their team members and dataset by 30 September 2026. 
• 
Duplicate datasets/topics across teams should be avoided. Dataset approval will be based on 
suitability and availability. 
• 
Students must cite the original dataset source in the final report.

5. Dataset Selection 
Each team must select one dataset from either Kaggle or the UCI Machine Learning Repository. The 
dataset should support a meaningful Machine Learning problem and should provide enough 
observations and features for analysis, modelling, and evaluation. 
 
The project may involve classification, regression, clustering, or another appropriate Machine 
Learning task. The selected task must be justified based on the problem and characteristics of the 
dataset. 
Students should first identify the real-world problem and then select an appropriate dataset and ML 
approach.

15. Data Leakage and Experimental Practice 
Students must ensure that information from the test set does not influence model training, 
preprocessing decisions, feature selection, or hyperparameter tuning. 
• 
Fit data-dependent preprocessing steps using training data only. 
• 
Do not use the test set to select hyperparameters. 
• 
Do not repeatedly inspect test performance and modify the model based on it. 
• 
Use pipelines where appropriate. 
• 
Identify and document features that may contain target or future information.
